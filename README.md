# Polymarket Maintenance POC

## Quick start in Codespaces

1. Open this repo in GitHub Codespaces
2. In the Codespace terminal:
    - Python deps are installed automatically by the devcontainer
    - Run: python src/polymkt_poc.py
3. Outputs are written to the output directory.

## Environment variables
- POLY_BASE_URL to override API base URL
- OUTPUT_DIR to change output location.
